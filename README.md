# 视听融合声源定位与目标跟踪云台

> **一句话总结**：基于树莓派的云台控制系统。声学负责在监听到拍手时“**往哪看一次**”，视觉负责接手后“**盯着左右跟**”。

---

## 🗂️ 核心架构与目录

```text
project/
├── 视听融合声源定位与目标跟踪云台-开发计划.md   # 详细需求与验收标准
├── 项目日志.md             # ⚠️ 每次开工前必读，记录进度与重要变更
├── configs/default.yaml    # 核心配置文件（阈值/限位/步长统一定义）
├── src/                    # 核心源码模块
│   ├── app.py              # 主入口：三线程 + 三态状态机
│   ├── audio.py            # 音频：采集 → 能量SED → GCC-PHAT定位
│   ├── vision.py           # 视觉：取流 → 人脸检测 → 像素偏差计算
│   └── servo.py / controller.py # 硬件底座：硬件PWM驱动与死区步进
├── scripts/                # 单模块测试脚本（如 healthcheck.py）
└── data/                   # 原始传感器测试数据（不进 git）
```

**运行逻辑 (三态状态机)**：
`IDLE` (静默监听) ──(拍手)──► `TURN_ONCE` (单次开环转向) ──(到位)──► `FOLLOW` (视觉死区跟随)

## 🔌 硬件接线（严格遵守）

```text
[官方 5V/3A] ──Type-C──► Raspberry Pi 4B
                              GPIO 18 (硬件 PWM) ──► 舵机信号线
[外置 5–6V / ≥3A] ─────► 舵机电源正极（红线）
        │                     │
       GND ◄──── 共地 ────► GND (Pi Pin 6 / 9) + 舵机负极
```

- ⛔ **严禁**：将舵机正极接到树莓派 5V 引脚（会导致欠压重启或烧毁）。
- ⚠️ **必须**：舵机外接独立电源，且**必须与树莓派共地**；电源端并联大电容。
- 🔄 **顺序**：先开舵机电源，再开树莓派；关机顺序相反。

## ⚙️ 快速启动

```bash
# 1. 运行健康检查 (CPU温度、设备状态)
python scripts/healthcheck.py

# 2. 启动硬件 PWM 守护进程 (必做)
sudo pigpiod

# 3. 运行主程序 (按 c 回中，按 q 退出)
python -m src.app --config configs/default.yaml
```

## 📋 极简开发约定

1. **工作交接看日志**：任何进度推进或遇到的问题，直接追加到 `项目日志.md`。
2. **源码拒绝硬编码**：所有硬件引脚、环境阈值、机械限位、控制步长一律写在 `default.yaml` 中。
3. **方向统一管理**：声源与人脸在左侧统一为负值，若实际云台转反，只需修改 YAML 中的 `servo_sign`，**绝不修改算法源码**。
