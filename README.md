# 视听融合声源定位与目标跟踪云台

目标流程：离线唤醒词「小爱同学」触发后，双麦（AC3104）从唤醒语音做一次 GCC-PHAT 粗测向并让云台转向，音箱回应「我在」，全局快门相机（OV9281）随后识别人脸并由两轴持续跟踪，实时画面通过 Web 页面显示。主程序集成代码已写入本地工作区，但最终验证尚未完成；代码尚未推送或部署到 Pi，Pi 端端到端联调未开始。

系统主线架构为：**2-DOF 串行总线舵机云台（Yaw+Pitch） + 微雪通用型 Bus Servo Adapter 驱动板 + 酷态科 6A 快充独立供电 + AC3104 双麦 + OV9281 全局快门相机 + YuNet 人脸检测 + 四态状态机调度**。
ArUco 工业靶标、50mW 激光器与 ESP32 协处理器已于 2026-11-22 移出范围；仓库内相关代码与配置段仅作兼容保留，主程序不再装配。

完整技术开发计划见[开发计划](docs/视听融合声源定位与目标跟踪云台-开发计划.md)；
前端接口协议规范见[Web前端总体架构与通信接口协议规范](docs/Web前端总体架构与通信接口协议规范.md)；
质量与抗压测试报告见[前端稳定性与功能完整性测试报告](docs/前端稳定性与功能完整性测试报告.md)；
现场物理接线与实机验证指南见[人工待办与硬件验证](docs/人工待办与硬件验证.md)；

- **`domain/`（领域层）**：纯领域逻辑与业务模型（`state_machine.py`、`controller.py`、`types.py`），零硬件与第三方依赖。

## 现代化 Web 战术座舱 HUD 监视与控制中心 (M7 Web HUD)

系统已全面集成轻量级、零构建依赖（Zero-Build）的现代化工业战术机甲风格 Web 前端控制大屏，专为树莓派 4B ARMv8 硬件优化设计，提供极速响应与全方位的视听伺服监控体验。

### 1. 一键极速启动与访问

```bash
# 方式 1：通过 Python 模块启动（默认自动启用 Web 服务，绑定 0.0.0.0:8080）
python -m pantilt --web

# 方式 2：使用已安装的命令行程序
pantilt --web

# 自定义端口启动
python -m pantilt --web --web-port 8888

# 仅终端操作（关闭 Web 服务与 API）
python -m pantilt --no-web
```

- **局域网/Wi-Fi/网线跨端访问**：在同一局域网下的任意电脑、平板或手机浏览器直接打开：
  `http://<树莓派IP>:8080` 或本地回环 `http://localhost:8080`；
- **两台树莓派分工**。连接相机、双麦和舵机的树莓派通过 SSH 启动主程序并保留 `--web`。在显示端树莓派打开 `http://<硬件端IP>:8080/`。硬件端运行检测、控制和接口，显示端的浏览器渲染网页。独立开发界面时，可用 `GET /api/stream/video?raw=1` 取视频、`GET /api/stream/events` 订阅遥测和事件。
- **拓展坞 HDMI 本地全屏投屏（Kiosk 模式）**：
  ```bash
  chromium-browser --kiosk --app=http://127.0.0.1:8080
  ```

1. **【视口 1】实况战术 HUD 视频视口 (Tactical Video HUD)**：
   - **底层视频流**：基于 MJPEG 协议通过 `GET /api/stream/video` 低延迟推流。连接相机时自动推送 OV9281 灰度视频流；脱机或无硬件环境下无缝自动回退至后台 Synthetic 动态正弦波靶标渲染器，实现脱机 100% 独立开发；
   - **顶层 Canvas 动态标定覆盖层**：采用 `requestAnimationFrame` 以 60 FPS 渲染自适应准星（寻的橙黄 `#ffaa00` / 锁定亮绿 `#00ff9d` 伴随呼吸光环）、死区瞄准虚线框、人脸外接框、准星至脸中心的动态偏差矢量引导线与 $(dx, dy)$ 像素读数；
   - **激光作业警示浮层**：激光器已移出范围，后端恒报 `is_on=false`，该横幅在当前方案下不会出现。
2. **【视口 2】空间声学极坐标雷达视口 (Acoustic Sonar Radar)**：
   - **极坐标声纳盘**：HTML5 Canvas 实时绘制 180° 前向（或 360° 全向）声纳网格、方位角刻度（$-90^\circ \sim +90^\circ$）与绿色透明旋转扫描光栅动画；
   - **声源瞬态指向指示**：基于 AC3104 双麦采样与 GCC-PHAT 计算的估计声源角 $\theta_{audio}$，动态渲染荧光绿高亮测向波束指针，波束扩散扇区反比于互相关置信度；
   - **左右声道立体声 VU 电平柱**：雷达两侧垂直渲染左 (Left) 与右 (Right) 实时音量跳动电平条；
   - **声学降级模式提示**：混响严重或低置信度下自动提示 `[MODE: ENERGY_DIFF DEGRADED]`。
3. **【视口 3】双轴云台姿态与交互控制台 (Gimbal Teleoperation Console)**：
   - **双轴半弧角度仪表盘**：水平偏航 Yaw（$-90^\circ \sim +90^\circ$）与垂直俯仰 Pitch（$-30^\circ \sim +45^\circ$）双向弧形刻度仪表，双指针指示当前物理角度与目标角度；
   - **2-DOF 虚拟触控摇杆**：支持鼠标拖拽与触摸屏滑动，摇杆位移实时映射为角速度增量与死区步进；
   - **运行模式平滑切换**：`AUTO`（自主视听跟踪）/ `MANUAL`（人工遥控接管）/ `CALIBRATION`（零点标定）；
   - **关键安全按键**：`[EMERGENCY CENTER]` 一键紧急归中（$(0^\circ, 0^\circ)$）、`[LASER TEST / CUTOFF]`（激光器已移出范围，按钮保留但后端恒返回关闭状态）。
4. **【视口 4】全系统遥测大屏与滚动终端控制台 (Telemetry & Terminal)**：
   - **关键指标遥测卡片群**：主循环运行频率（Target: 30~50 Hz）、实际检测 FPS、状态机当前状态徽章与驻留计时、连续锁定帧数计数器、目标脱靶丢失计时器、CPU 温度与 Uptime；
   - **战术机甲滚动终端**：深黑背景等宽终端，实时消费 SSE 日志流，等级着色（DEBUG灰/INFO青绿/WARN橙/ERROR红），支持等级过滤与自动滚屏锁底；
   - **运行时参数动态热更抽屉**：支持在前端直接微调死区阈值（`deadzone_px`）、步进角度（`step_deg`）、检测模式（`aruco`/`face`），通过 `POST /api/config` 实时热更，无需重启主控进程。

### 3. 全局键盘热键与战术声效

在 Web HUD 界面任意位置可使用以下全局键盘热键进行操作接管：

| 快捷键 | 功能动作 | 安全保障机制 |
| :--- | :--- | :--- |

## 硬件电气接线与供电安全

```text
[酷态科 6A 快充头] ──Type-C──> [Type-C 诱骗线 (9V/12V)] ──> [微雪总线驱动板 VIN 端子]
                                                                    │
                                                      串行总线 3-Pin (菊花链 Daisy Chain)
                                                                    │
                                                      ┌─────────────┴─────────────┐
                                                      ▼                           ▼
                                            [水平舵机 Yaw (ID 1)]       [俯仰舵机 Pitch (ID 2)]

[树莓派官方 5V/3A 电源] ──Type-C──> [树莓派 4B]
                                      │
                                      ├── [USB 3.0] ──> [OV9281 120fps 全局快门相机]
                                       ├── [GPIO 排针] ─> [AC3104 双麦 HAT] ──SPK──> [小音箱]
                                      ├── [USB 转串口] ─> [微雪驱动板串口]
                                      │
                                      └── [GND 共地线] ───────────────────────────> [微雪驱动板 GND]
```

- **严禁接混**：微雪驱动板输入的是诱骗出的 9V 或 12V 动力高压，**绝对禁止接入树莓派任何 5V 或 3.3V 引脚**！
- **必须共地**：树莓派 GND 与微雪驱动板 GND 必须使用杜邦线紧密相连，以保证串口信号电平一致。
- **上电次序**：先开酷态科舵机电源，使总线舵机上电寻址并进入保持状态；再开树莓派电源。关机时相反。

## 控制台交互快捷键

当主程序在终端交互式运行时：
- 输入 `c` 并回车：两轴舵机平稳归中 (0°, 0°)，系统状态复位为 `IDLE`（重新监听声音）。
- 输入 `q` 并回车：按规范顺序安全停止所有模块并退出程序。
- 随时按 `Ctrl+C` 亦可触发优雅退出与资源释放。
