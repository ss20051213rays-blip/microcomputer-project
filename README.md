# 视听融合声源定位与目标跟踪云台（2-DOF 总线伺服版）

基于 Raspberry Pi 4B 与微雪串行总线舵机平台的二维视听融合微系统：声学（WM8960 双麦）负责在拍手突发声后精准粗定“往哪看一次”，全局快门相机（OV9281 120fps）负责转向后“两轴精准锁定目标”，50mW 小型激光器在锁定准星瞬间提供物理命中指示。

系统主线架构为：**2-DOF 串行总线舵机云台（Yaw+Pitch） + 微雪通用型 Bus Servo Adapter 驱动板 + 酷态科 6A 快充独立供电 + OV9281 120fps 全局快门相机 + ArUco 工业靶标 (DICT_4X4_50) / 人脸双模检测 + 50mW 物理激光瞄准指示 + 三态状态机调度**。

完整技术开发计划见[开发计划](视听融合声源定位与目标跟踪云台-开发计划.md)，需要现场物理接线与实机验证的事项见[人工待办与硬件验证](人工待办与硬件验证.md)，全部历史变更与测试证据见[项目日志](项目日志.md)。

## 架构与数据流

```text
WM8960 硬件双麦 -> sounddevice 回调 -> 有界 PCM 队列 -> SED 突发检测 -> GCC-PHAT 测角
                                                                            │
OV9281 相机 (120fps 全局快门) -> CameraCapture 最新帧 -> ArUco / 人脸检测 -> (dx, dy)
                                                                            │
                                   主控循环 (约 30~50 Hz)
                         IDLE ──(拍手)──> TURN_ONCE ──(到位平息)──> FOLLOW
                                                                      │
                                                           两轴死区步进控制器
                                                                      │
                                                ┌─────────────────────┴─────────────────────┐
                                                ▼                                           ▼
                                   微雪总线舵机二维平台 (Yaw, Pitch)                  50mW 激光瞄准指示器
                                   Half-Duplex UART 协议帧下发与回读                 稳定锁定点亮，脱靶即灭
```

## 硬件电气接线与供电安全

```text
[酷态科 6A 快充头] ──Type-C──> [Type-C 诱骗线 (9V/12V)] ──> [微雪总线驱动板 VIN 端子]
                                                                    │
                                                      串行总线 3-Pin (菊花链 Daisy Chain)
                                                                    │
                                                      ┌─────────────┴─────────────┐
                                                      ▼                           ▼
                                            [水平舵机 Yaw (ID 1)]       [俯仰舵机 Pitch (ID 2)]

[树莓派官方 5V/3A 电源] ──Type-C──> [树莓派 4B]
                                      │
                                      ├── [USB 3.0] ──> [OV9281 120fps 全局快门相机]
                                      ├── [GPIO 排针] ─> [WM8960 硬件双麦模块]
                                      ├── [GPIO 23] ──> [50mW 激光器驱动控制]
                                      ├── [USB 转串口] ─> [微雪驱动板串口]
                                      │
                                      └── [GND 共地线] ───────────────────────────> [微雪驱动板 GND]
```

- **严禁接混**：微雪驱动板输入的是诱骗出的 9V 或 12V 动力高压，**绝对禁止接入树莓派任何 5V 或 3.3V 引脚**！
- **必须共地**：树莓派 GND 与微雪驱动板 GND 必须使用杜邦线紧密相连，以保证串口信号电平一致。
- **上电次序**：先开酷态科舵机电源，使总线舵机上电寻址并进入保持状态；再开树莓派电源。关机时相反。
- **激光安全**：50mW 激光器禁止直射人眼或对准窗外；软件具备 10 秒超时强制熄灭保护。

## 控制台交互快捷键

当主程序在终端交互式运行时：
- 输入 `c` 并回车：强制熄灭激光器、两轴舵机平稳归中 (0°, 0°)，系统状态复位为 `IDLE`（重新监听声音）。
- 输入 `q` 并回车：按规范顺序安全停止所有模块并退出程序。
- 随时按 `Ctrl+C` 亦可触发优雅退出与资源释放。
