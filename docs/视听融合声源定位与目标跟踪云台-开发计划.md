5. **M7 交互多媒体增强**：接上拓展坞 HDMI 屏幕，开启 HUD 实时画面与语音播报。

## 1. 项目概述

### 1.1 一句话目标

平时系统低功耗监听环境。检测到拍手 / 敲击后，WM8960 硬件双麦通过 GCC-PHAT 计算水平方向角，二维总线云台开环快速转向声源；到位后切入 OV9281 高帧率全局快门视觉闭环，利用 ArUco 工业靶标或人脸实时解算二维偏差 $(dx, dy)$，实现水平 (Yaw) 与俯仰 (Pitch) 视轴精准伺服；目标稳定对准死区准星瞬间点亮 50mW 小型激光器进行物理指示；目标脱离视场后自动熄灭激光并平稳回中。

**“声学管粗定偏航，视觉管精跟双轴，激光管物理指引，总线管刚性伺服”。**

### 1.2 核心基础功能（课程必须完成）

1. **声源水平粗定位**：WM8960 双通道立体声硬件同步采集，拍手触发后 GCC-PHAT 输出水平角度（或可靠左右侧别）。
2. **高速二维目标解算**：OV9281 全局快门相机以最高 120 FPS 采集，无果冻效应；ArUco 工业靶标（DICT_4X4_50）/ 人脸检测输出双轴偏差 $(dx, dy)$。
3. **2-DOF 总线伺服闭环**：微雪串行总线舵机平台根据 $(dx, dy)$ 进行死区步进闭环，消除水平与垂直跟踪误差。
4. **物理激光瞄准指示**：目标进入死区准星且连续锁定后点亮 50mW 激光器，物理命中目标；失锁或超时具备安全联锁自动熄灭。
5. **独立大电流供电保障**：酷态科 6A 快充 + 诱骗线独立供电，连续演示 ≥10 分钟绝无欠压重启。

### 1.3 拓展与特色功能（基础闭环稳定后实施）

- **微机异构双脑协同**：树莓派 4B（Linux，负责图像/音频/FSM）+ ESP32（FreeRTOS，负责硬实时舵机协议插补、激光控制与看门狗）。
- **实况 HUD 监视仪表盘**：通过通用拓展坞 HDMI 端口连接屏幕，实时渲染 120fps 视频流、中心十字准星、目标外接框、两轴角度、电压与 FPS。
- **视觉锁定语音播报**：目标对齐瞬间，通过 WM8960 耳机/音频输出单次播报“目标已锁定”。
- **3D 空间位姿估计**：利用 ArUco $rvec, tvec$ 输出目标在三维空间中的距离与欧拉角。

### 1.4 成功标准量化矩阵

| 指标维度 | 基础及格线（必须完成） | 卓越标准（全面达到） |
| --- | --- | --- |
| **开环转向响应** | 拍手到舵机开始动作 ≤0.5 s；转向正确侧别 ≥85% | 拍手响应 ≤0.3 s；方位角误差 ≤±10° |
| **视觉采样帧率** | 稳定在 30~60 FPS，无丢帧卡顿 | OV9281 达到 **90~120 FPS**，单帧耗时 ≤8 ms |
| **目标跟踪精度** | ArUco 靶标在 2 m 处移动，云台平稳跟随不脱靶 | 双轴死区收敛至 ±20 px，激光直击 12cm 靶心 |
| **系统供电稳定性** | 酷态科电源独立供电，连续运行 5 min 零欠压 | 连续双轴压测 **15 min**，CPU 温度稳定 ≤60°C |
| **安全与保护机制** | 限位有效防止绞线；目标丢失 3 s 内归中 | 激光点亮超过 10 s 自动切断防过热；失锁毫秒级熄灭 |

## 2. 开发原则与技术路线

### 2.1 硬件升级驱动的开发原则

| 原则 | 实施细则 |
| --- | --- |
| **总线优先，平滑兼容** | 全面切换至微雪串行总线舵机作为主控执行机构，代码架构上抽象统一接口，保留旧版 PWM 逻辑作为降级回退 |
| **供电物理隔离** | 严禁任何舵机正极借用树莓派 GPIO 5V；酷态科 6A 快充通过 Type-C 诱骗线专供微雪驱动板，树莓派与驱动板仅共地 |
| **双模视觉基准** | 将 ArUco 工业靶标作为算法精度和高帧率闭环的 Ground Truth 标准；将人脸检测作为人机交互演示的标准 |
| **软硬件安全联锁** | 50mW 激光器必须具备状态联锁（仅在 FOLLOW 且稳定在准星内才允许点亮）与超时强制切断（最大 10s），防人眼直射与过热 |
| **异构分层实施** | 优先打通树莓派通过 USB 串口直连微雪总线板的极速链路；基础闭环稳定后，再将 ESP32 串入作为硬实时协处理器 |

**电气安全规范**：
1. **地线严格共地**：树莓派 GND 引脚与微雪总线驱动板的 GND 必须通过导线稳固连接，确保串口逻辑电平参考一致。

3. **上电顺序**：先开启酷态科舵机电源，使微雪驱动板与舵机上电寻址；再开启树莓派电源。关机时相反。

### 4.3 模块接口与数据结构

```python
@dataclass
class AudioEvent:
    timestamp_mono: float       # 单调时钟时间戳
    theta_audio_deg: float      # 水平估计角度 (-90° ~ +90°)
    side: str                   # 侧别 ("left" | "right" | "center")
    confidence: float           # GCC-PHAT 互相关峰值置信度 (0~1)
    method: str                 # "gcc_phat" 或 "energy_diff"

@dataclass
class VisionObservation:
    timestamp_mono: float       # 时间戳
    face_found: bool            # 目标是否存在 (兼容 ArUco 与人脸)
    dx_px: float                # 水平像素偏差 (左负右正)
    bbox: tuple                 # (x, y, w, h)
    confidence: float           # 置信度
    fps: float                  # 实时帧率
    dy_px: float = 0.0          # 垂直像素偏差 (上负下正)
    target_id: int = -1         # 检出的 ArUco 标记 ID

class ServoController:
    def set_angles(self, yaw=None, pitch=None): ... # 双轴独立或联动设置
    def step(self, delta_yaw, delta_pitch=0.0): ... # 双轴步进
    def center(self): ...                           # 双轴归中 (0°, 0°)
    def get_angles(self) -> (float, float): ...     # 获取实时双轴角度
    def disable(self): ...                          # 释放总线扭矩
```

## 7. 风险规避与再降级预案

| 风险点 | 表现特征 | 保底与降级预案 |
| :--- | :--- | :--- |
| **总线舵机串口无响应** | 驱动板串口无法打开或通信超时 | 1. 检查酷态科诱骗线电压（9V/12V）与共地接线；2. 降级为备用 GPIO 18 SG90 PWM 模式 |
| **室内严重混响导致声学乱转** | GCC-PHAT 互相关峰值杂乱，测角跳变 | 自动切换为能量差降级模式（固定左转 30° / 右转 30°），声学只定侧别，靠视觉找目标 |
| **120fps 取流 USB 带宽受限** | OpenCV 报错或偶发丢帧 | 将取流分辨率由 1280x800 下调为 640x400，并锁定灰度格式（Y800 / GREY）降低吞吐量 |
| **激光器持续照射引起安全隐患** | 操作人员可能直视激光光束 | 1. 软件强制限制在连续跟踪中心死区时才点亮；2. 强制 10s 自动熄灭；3. 调试期间佩戴护目镜 |
| **ESP32 联调进度滞后** | 固件通信协议联调耗费时间 | 直接采用树莓派 4B USB 串口直连微雪总线驱动板方案，不阻塞主线系统交付与答辩演示 |

## 8. 总结与执行铁律

1. **先通微雪总线舵机，再接传感器**：总线平台是全系统执行骨架，必须先确保两轴平稳扫掠与安全限位。
2. **严守独立大电流供电**：酷态科 6A 快充 + 诱骗线专供驱动板，严禁舵机接树莓派 5V。
3. **ArUco 是标尺，人脸是交互**：先用 5mm 哑光雪弗板靶标调通高速闭环与激光命中，再做人脸演示。
4. **单调时钟与安全联锁**：所有控制超时与激光点亮时长均使用 `time.monotonic()` 严格计算，避免系统时间跳变引发故障。
