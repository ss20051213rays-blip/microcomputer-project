## 1. 项目概述

### 1.1 一句话目标

平时系统低功耗监听环境。检测到拍手 / 敲击后，WM8960 硬件双麦通过 GCC-PHAT 计算水平方向角，二维总线云台开环快速转向声源；到位后切入 OV9281 高帧率全局快门视觉闭环，利用 ArUco 工业靶标或人脸实时解算二维偏差 $(dx, dy)$，实现水平 (Yaw) 与俯仰 (Pitch) 视轴精准伺服；目标稳定对准死区准星瞬间点亮 50mW 小型激光器进行物理指示；目标脱离视场后自动熄灭激光并平稳回中。

**“声学管粗定偏航，视觉管精跟双轴，激光管物理指引，总线管刚性伺服”。**

### 1.2 核心基础功能（课程必须完成）

1. **声源水平粗定位**：WM8960 双通道立体声硬件同步采集，拍手触发后 GCC-PHAT 输出水平角度（或可靠左右侧别）。
2. **高速二维目标解算**：OV9281 全局快门相机以最高 120 FPS 采集，无果冻效应；ArUco 工业靶标（DICT_4X4_50）/ 人脸检测输出双轴偏差 $(dx, dy)$。
3. **2-DOF 总线伺服闭环**：微雪串行总线舵机平台根据 $(dx, dy)$ 进行死区步进闭环，消除水平与垂直跟踪误差。
4. **物理激光瞄准指示**：目标进入死区准星且连续锁定后点亮 50mW 激光器，物理命中目标；失锁或超时具备安全联锁自动熄灭。
5. **独立大电流供电保障**：酷态科 6A 快充 + 诱骗线独立供电，连续演示 ≥10 分钟绝无欠压重启。

### 1.3 拓展与特色功能（基础闭环稳定后实施）

- **微机异构双脑协同**：树莓派 4B（Linux，负责图像/音频/FSM）+ ESP32（FreeRTOS，负责硬实时舵机协议插补、激光控制与看门狗）。
- **现代化 Web 实况战术 HUD 与遥测控制大屏**：提供四象限座舱布局（实况视频 HUD、空间声学极坐标雷达、双轴云台虚拟摇杆控制台、系统遥测与滚动控制台），支持千兆网口 / Wi-Fi 远程访问与拓展坞 HDMI 本地全屏投屏双模。
- **视觉锁定语音播报**：目标对齐瞬间，通过 WM8960 耳机/音频输出单次播报“目标已锁定”。
- **3D 空间位姿估计**：利用 ArUco $rvec, tvec$ 输出目标在三维空间中的距离与欧拉角。

### 1.4 成功标准量化矩阵

| 指标维度 | 基础及格线（必须完成） | 卓越标准（全面达到） |
| --- | --- | --- |
| **开环转向响应** | 拍手到舵机开始动作 ≤0.5 s；转向正确侧别 ≥85% | 拍手响应 ≤0.3 s；方位角误差 ≤±10° |
| **视觉采样帧率** | 稳定在 30~60 FPS，无丢帧卡顿 | OV9281 达到 **90~120 FPS**，单帧耗时 ≤8 ms |
| **目标跟踪精度** | ArUco 靶标在 2 m 处移动，云台平稳跟随不脱靶 | 双轴死区收敛至 ±20 px，激光直击 12cm 靶心 |
| **系统供电稳定性** | 酷态科电源独立供电，连续运行 5 min 零欠压 | 连续双轴压测 **15 min**，CPU 温度稳定 ≤60°C |

## 2. 开发原则与技术路线

### 2.1 硬件升级驱动的开发原则

| 原则 | 实施细则 |
| --- | --- |
| **总线优先，平滑兼容** | 全面切换至微雪串行总线舵机作为主控执行机构，代码架构上抽象统一接口，保留旧版 PWM 逻辑作为降级回退 |
| **供电物理隔离** | 严禁任何舵机正极借用树莓派 GPIO 5V；酷态科 6A 快充通过 Type-C 诱骗线专供微雪驱动板，树莓派与驱动板仅共地 |
| **双模视觉基准** | 将 ArUco 工业靶标作为算法精度和高帧率闭环的 Ground Truth 标准；将人脸检测作为人机交互演示的标准 |
| **软硬件安全联锁** | 50mW 激光器必须具备状态联锁（仅在 FOLLOW 且稳定在准星内才允许点亮）与超时强制切断（最大 10s），防人眼直射与过热 |
| **异构分层实施** | 优先打通树莓派通过 USB 串口直连微雪总线板的极速链路；基础闭环稳定后，再将 ESP32 串入作为硬实时协处理器 |

1. **地线严格共地**：树莓派 GND 引脚与微雪总线驱动板的 GND 必须通过导线稳固连接，确保串口逻辑电平参考一致。

3. **上电顺序**：先开启酷态科舵机电源，使微雪驱动板与舵机上电寻址；再开启树莓派电源。关机时相反。

### 4.3 模块接口与数据结构

```python
@dataclass
class AudioEvent:
    timestamp_mono: float       # 单调时钟时间戳
```

### 4.4 Web 前端通信协议与遥测 DTO 契约 (M7 演进)

基于 Clean Architecture 架构原则，Web 交互层作为 Presentation/Runtime 适配器收敛于 `src/pantilt/adapters/web/`，严格遵循单向依赖规则，向内消费 `application/tracker` 与 `domain` 状态。
通信层由 **REST API**（命令与状态查询）、**Server-Sent Events (SSE)**（高频遥测广播）与 **MJPEG**（低延迟视频推流）组成。

#### 1. REST 与流式路由总表 (`WebRoutes`)
- `GET /` & `GET /static/*`: 自包含原生静态资源单页应用入口与样式脚本；
- `GET /api/status`: 系统宏观健康度、运行模式与主循环频率；
- `GET /api/telemetry`: 全量状态快照（舵机、视觉、声学、激光、系统指标）；
- `GET /api/stream/events`: SSE 持续事件广播流（`telemetry`, `acoustic`, `state_change`, `alert`, `log`）；
- `GET /api/stream/video`: MJPEG 实时视频流（支持实机 OV9281 取流与脱机 Synthetic 动态靶标 Mock）；
- `POST /api/control/servo`: 双轴角度控制（支持绝对角度控制与增量步进微调，严格执行物理限位截断）；
- `POST /api/control/center`: 云台双轴一键安全归中；
- `POST /api/control/laser`: 激光器人工强制作业切断与点亮测试（受 10s 硬件与网络超时双重保护）；
- `POST /api/control/mode`: 运行模式平滑切换（`AUTO` 自主跟踪 / `MANUAL` 人工遥控 / `CALIBRATION` 标定）；
- `GET/POST /api/config`: 运行时参数读取与动态热更（死区阈值、步进角等）；
- `GET /api/logs`: 滚动日志缓冲区快照。

1. **【视口 1】实况战术 HUD 视频视口 (Tactical Video HUD)**：
   - **底层视频流**：基于 MJPEG 协议通过 `<img>` 标签直接展示 `/api/stream/video` 视频帧。支持接入真实 OV9281 相机（640x400 @ 30fps 取流），若无硬件则无缝回退至后台 Synthetic 动态正弦波靶标渲染器，实现脱机 100% 仿真；
   - **顶层 Canvas 动态标定覆盖层**：采用 `requestAnimationFrame` 以 60 FPS 渲染：
     - 动态中心十字瞄准准星：根据跟踪状态智能切换（寻的阶段为琥珀橙 `#ffaa00`，死区锁定阶段为荧光绿 `#00ff9d` 伴随呼吸光环）；
     - 靶标与偏差矢量指示：动态绘制目标边界框（ArUco 工业靶标角点与 ID 标识、或人脸检测框），并在靶心与准星之间绘制动态引导引线及 $(dx, dy)$ 偏差像素读数；
     - 激光作业警示浮层：当检测到激光器激活时，在视口顶部弹出亮红色 `[LOCKED - LASER ACTIVE]` 警示横幅与持续点亮安全倒计时条（0.0s ~ 10.0s）。

2. **【视口 2】空间声学极坐标雷达视口 (Acoustic Sonar Radar)**：
   - **极坐标扫描盘**：HTML5 Canvas 实时绘制 180° 前向（或 360° 全向）声纳雷达同心圆网格、方位角刻度（$-90^\circ \sim +90^\circ$）与绿色透明旋转扫描光栅动画；
   - **声源瞬态指向指示**：基于 WM8960 采集与 GCC-PHAT 计算的估计声源角 $\theta_{audio}$，动态渲染荧光绿高亮测向波束指针，波束扩散扇形角度反比于互相关置信度 $confidence$；
   - **双声道立体声 VU 电平柱**：雷达两侧垂直渲染左声道 (Left) 与右声道 (Right) 实时音量 VU 电平条，以跳动的发光 LED 矩阵柱动态反映环境音量；
   - **声学降级模式浮窗**：当处于走廊严重混响等低置信度环境导致 GCC-PHAT 降级为能量差模式时，雷达中央显式弹出 `[MODE: ENERGY_DIFF DEGRADED]` 琥珀色指示牌。

3. **【视口 3】双轴云台仪表与交互遥控台 (Gimbal Teleoperation Console)**：
   - **双轴半弧角度仪表盘**：
     - 水平偏航 Yaw（$-90^\circ \sim +90^\circ$）与垂直俯仰 Pitch（$-30^\circ \sim +45^\circ$）双向弧形刻度仪表；
     - 双指针设计：当前物理角度指针（实线高亮）与目标下发角度指针（虚线半透明），直观展现舵机闭环响应动态；
     - 状态指标标签：实时展示舵机扭矩使能状态、总线通信健康度与微雪驱动板回读工作电压；

##### 8.1.3 通信协议设计与安全联锁规范
1. **RESTful API 契约**：
   - 包含系统状态、全量快照、舵机控制、一键归中、激光控制、模式切换、配置热更与日志查询 8 项标准接口，输入输出均采用紧凑 JSON 格式（详见 Section 4.4）。
2. **Server-Sent Events (SSE) 高频广播**：
   - 客户端单向保持 HTTP 长连接，无需 WebSocket 复杂握手开销；
   - 后端遥测线程以 20~30 Hz 广播全量 `TelemetryPacketDTO`，突发声学事件时即时推送 `acoustic` 帧，状态机跳变时推送 `state_change` 帧，发生异常时推送 `alert` 帧。
3. **安全限位拦截与双重联锁机制**：
   - **舵机越界软硬件拦截**：所有来自 Web 的手动控制指令（步进或绝对）必须经由 `ServoControlCommand.validate_and_clamp` 拦截并强制裁剪至 $[-90^\circ, +90^\circ]$ (Yaw) 与 $[-30^\circ, +45^\circ]$ (Pitch)，物理死区与硬限位绝不撞墙；
   - **激光超时单调时钟硬保护**：无论通过 Web 还是状态机点亮激光，后端均使用 `time.monotonic()` 进行单调时钟硬看门狗计时，到达 10.0 秒无条件拉低 GPIO 强行熄灭，防止激光器过热或人眼误伤；
   - **网络失联安全降级**：处于 `MANUAL` 人工模式下，若超过 5.0 秒未收到任何 Web 控制输入或心跳请求，系统立即向终端输出告警，自动平稳归中舵机并转回 `AUTO` 状态机监听模式。

## 7. 风险规避与再降级预案

| 风险点 | 表现特征 | 保底与降级预案 |
| :--- | :--- | :--- |
| **总线舵机串口无响应** | 驱动板串口无法打开或通信超时 | 1. 检查酷态科诱骗线电压（9V/12V）与共地接线；2. 降级为备用 GPIO 18 SG90 PWM 模式 |
| **室内严重混响导致声学乱转** | GCC-PHAT 互相关峰值杂乱，测角跳变 | 自动切换为能量差降级模式（固定左转 30° / 右转 30°），声学只定侧别，靠视觉找目标 |
| **120fps 取流 USB 带宽受限** | OpenCV 报错或偶发丢帧 | 将取流分辨率由 1280x800 下调为 640x400，并锁定灰度格式（Y800 / GREY）降低吞吐量 |
| **激光器持续照射引起安全隐患** | 操作人员可能直视激光光束 | 1. 软件强制限制在连续跟踪中心死区时才点亮；2. 强制 10s 自动熄灭；3. 调试期间佩戴护目镜 |
| **ESP32 联调进度滞后** | 固件通信协议联调耗费时间 | 直接采用树莓派 4B USB 串口直连微雪总线驱动板方案，不阻塞主线系统交付与答辩演示 |
| **Web 多客户端连接导致树莓派负荷过重** | 多设备同时打开 Web 导致 CPU 占用升高或卡顿 | 1. 单进程限制最大并发 SSE 连接数（默认 4 个）；2. MJPEG 直推底层 OpenCV/缓存已编码 JPEG 字节流，坚决避免二次压缩 |
| **人工遥控网络卡顿或页面崩溃造成云台失控** | 处于 MANUAL 模式时浏览器异常关闭，云台保持原角度或失控 | 后端内置 5s 心跳看门狗：超过 5s 未收到任何控制输入，自动发出报警日志，安全平滑归中并自动切回 AUTO 自主状态机 |

## 8. 总结与执行铁律

1. **先通微雪总线舵机，再接传感器**：总线平台是全系统执行骨架，必须先确保两轴平稳扫掠与安全限位。
2. **严守独立大电流供电**：酷态科 6A 快充 + 诱骗线专供驱动板，严禁舵机接树莓派 5V。
3. **ArUco 是标尺，人脸是交互**：先用 5mm 哑光雪弗板靶标调通高速闭环与激光命中，再做人脸演示。
4. **单调时钟与安全联锁**：所有控制超时与激光点亮时长均使用 `time.monotonic()` 严格计算，避免系统时间跳变引发故障。
