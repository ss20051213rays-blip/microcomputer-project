### 4.3 云台双轴移动、归中、复位及软限位保护
- **测试用例**：`test_servo_motion_center_reset_and_boundary_clamping`、`test_gimbal_soft_limits_exhaustive_boundaries`
- **验证项**：
  - **增量步进 (Step Mode)**：测试下发 $\Delta \text{yaw}=+15.0^\circ, \Delta \text{pitch}=+10.0^\circ$，舵机准确响应并返回 `clamped=False`；连续反向调整 $\Delta \text{yaw}=-25.0^\circ, \Delta \text{pitch}=-15.0^\circ$，步进精度优于 $0.01^\circ$；
  - **绝对定位 (Absolute Mode)**：直接设定 $(+35.0^\circ, -20.0^\circ)$，两轴姿态精确到位；
  - **软限位截断保护 (Clamping)**：
    - 正向严重越界：下发 $(+150.0^\circ, +80.0^\circ)$，算法截断至物理极限 $(+90.0^\circ, +45.0^\circ)$，返回 `clamped=True`；
    - 负向严重越界：下发 $(-180.0^\circ, -90.0^\circ)$，算法截断至物理极限 $(-90.0^\circ, -30.0^\circ)$，返回 `clamped=True`；
    - 临界边界测试：下发精确边界点 $(+90.0^\circ, +45.0^\circ)$ 与 $(-90.0^\circ, -30.0^\circ)$，准确通过且 `clamped=False`；
    - 累加步进锁死防发散：在已达极限 $(+90.0^\circ, +45.0^\circ)$ 状态下，连续 5 次执行同向步进 $(+10^\circ, +5^\circ)$，角度始终锁定在极限且持续报警 `clamped=True`；
  - **一键回中与复位**：调用 `POST /api/control/center` 快速归零 $(0.0^\circ, 0.0^\circ)$；调用 `POST /api/control/reset`，状态机安全复位至初始 `IDLE` 状态。

### 4.4 激光控制、运行模式切换与安全联锁
- **测试用例**：`test_laser_control_and_mode_switching`、`test_laser_continuous_timeout_and_thermal_protection`
- **验证项**：
  - **模式切换**：支持 `AUTO`、`MANUAL`、`CALIBRATION` 平滑切换，输入未知模式时返回 400 拦截；
  - **强制开启与熄灭**：下发 `enable=True, force_override=True`，50mW 物理激光指示器点亮；下发 `enable=False`，激光瞬间熄灭；
  - **安全超时断开 (Thermal Protection)**：模拟持续开启时间超过配置上限 $t \ge 10.0\text{s}$，底层驱动及 Web 遥测巡检自动触发断开保护，强制将 `is_on` 置为 `False`，有效杜绝激光二极管烧毁与人眼隐患；
  - **失锁瞬态切断**：在死区锁定状态下点亮激光，当目标移出死区或失锁时（`in_deadzone=False`），激光立即熄灭；
  - **人工介入控制权保护**：系统在 `AUTO` 模式运行时，一旦操作人员通过 Web 控制台手动微调舵机，系统自动降级切入 `MANUAL` 模式，避免后台自动状态机抢占舵机控制权。

### 4.7 连续长时间持续轮询与视频推流测试 (无内存泄漏)

### 4.8 极端边界与畸形参数 Fuzzing 输入容错
- **测试用例**：`test_extreme_inputs_and_malformed_fuzzing`
- **恶意/畸形样本测试集**：
  1. **截断与畸形 JSON**：发送 `b"{broken_json: 123"`、`b"{\"mode\": \"step\", \"delta_yaw\": "`、`b"[1, 2, 3,"` 以及非 UTF-8 乱码字节 `b"\x00\x01\x02\xff\xfe"`；
  2. **类型混淆攻击**：`delta_yaw="not_a_number"`、`delta_yaw={"nested": 123}`；

- **防护结果**：服务端统一返回合规的 **HTTP 400 Bad Request** 或 **HTTP 404 Not Found** JSON 错误响应，系统内部捕获异常并拦截，**未引发任何 500 内部错误，服务端持续保持健康运行**。

### 4.9 网络异常中断与断线重连恢复验证
- **测试用例**：`test_network_disconnect_and_reconnection_resilience`
- **故障注入场景**：
  - 模拟客户端建立 `/api/stream/events` 长连接，在接收首帧数据后立即执行原始套接字 `s.close()`（模拟客户端断网、拔网线或浏览器强退）；
  - 模拟客户端在 MJPEG 视频流中途突发重置连接；

## 5. 关键缺陷发现、修复与深度安全加固

在本次测试工程师的严苛边界探测与 Fuzzing 测试中，共发现并闭环修复了 **4 处潜在缺陷与代码规范隐患**：

| 缺陷编号 | 发现阶段 / 场景 | 问题现象与机理分析 | 修复与安全加固措施 | 验证状态 |
| :--- | :--- | :--- | :--- | :--- |
| **BUG-01** | Fuzzing 异常输入探测 | 在向 `/api/control/servo` 发送 `{"delta_yaw": "NaN"}` 或 `"Infinity"` 时，Python 内置 `float("NaN")` 不抛出 `ValueError`，导致非法非数（NaN）流入舵机控制，绕过原有 `max/min` 限位运算并在 Python 中引发不可预测的比较混乱。 | 1) 在 `server.py` 中引入 `_parse_finite_float` 辅助函数，对 `math.isnan()` 与 `math.isinf()` 进行严格防御拦截并返回 400 错误；<br>2) 在 `protocol.py` 中的 `ServoControlCommand.validate_and_clamp` 加入针对 NaN/Inf 的兜底免疫逻辑，遇非法值自动回退为当前角。 | ✅ 已加固并通过测试 |
| **BUG-02** | 动态热更功能核查 | 原 `WebRuntimeAdapter` 的 `get_config_dict` 与 `update_config` 仅支持死区与步长更新，缺失对 `target_mode`（`aruco`/`face`）在线动态切换的支持，导致前端切换目标识别模式无法实时作用于底层感知层。 | 在 `server.py` 中补全了 `target_mode` 读写接口与底层 `app.vision` 的配置联动，并在遥测 DTO 中建立 `target_type` 随目标模式动态映射机制。 | ✅ 已加固并通过测试 |
| **BUG-03** | 激光器过热安全联锁 | 当系统处于 Web 手工模式且自主状态机未循环驱动时，如果用户通过 Web 强制点亮激光，激光器可能因缺少主循环触发而无法在 10s 后自动断开。 | 在 `WebRuntimeAdapter.build_telemetry()` 遥测巡检逻辑中加入主动安全断开检测：若 `now - on_start_mono > max_continuous_s`，自动调用 `laser.set_laser(True, now)` 触发强制过热保护熄灭。 | ✅ 已加固并通过测试 |
| **WARN-01** | 控制台日志与版本兼容 | Python 3.12+ 环境下，`datetime.utcnow()` 被标记为弃用警告（DeprecationWarning），影响自动化测试日志整洁度。 | 全面替换为标准库推荐的 `datetime.now(timezone.utc)`，全套测试运行实现 **0 warnings**。 | ✅ 已消除警告 |
