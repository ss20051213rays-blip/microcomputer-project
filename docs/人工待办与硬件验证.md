## 阶段一：动力供电、散热与总线舵机

- [x] **任务 1：动力供电与微雪驱动板电气接线**
  - **操作要点**：
    1. 诱骗线输出 9 V / 12 V 接驱动板 **VIN / GND**；万用表确认极性与电压。
    2. 驱动板 **GND** 与树莓派 **GND** 用杜邦线共地。
    3. 驱动板 USB 直连树莓派；云台两颗舵机菊花链接入总线端口。
    4. **【绝对禁忌】**：诱骗线 9 V / 12 V 绝不能接树莓派 5 V 或 3.3 V 引脚。
  - **人工反馈**：✅ 供电回读 **11.9 V**，共地稳固，驱动板指示灯正常。

- [x] **任务 2：树莓派散热安装与健康检查复查**
  - **人工反馈**：✅ 空载 CPU 约 38~40°C；11-26 跟踪负载下 1.8 GHz、37–39°C、`get_throttled=0x0`。

- [x] **任务 3：微雪总线舵机 ID 分配、扫掠、方向符号与零位**
  - **⚠ 实机踩坑记录（2026-11-21 / 22，全部实测）**：
    1. **波特率是 115200 不是 1 Mbps**：本批 SP-15S 出厂档位寄存器 `0x06 = 4`；1 Mbps **完全无应答（0/20）**。
    2. **必须拉高 RTS**：不拉高时应答命中率仅 1/12~7/12，拉高后 10/10。已固化为 `servo.serial_rts: true`。
    3. **两颗舵机出厂 ID 都是 0**：同 ID 抢答冲撞表现为「一条命令两颗同时动」、位置回读出现 `41471` 这类超范围值、单次 Ping 收到上万重复帧。**不是舵机坏了**，逐颗改 ID 即可。
    4. **驱动板被过压打伤的判断**：板载 MCU 打印 `App_IWDG_SystemReset` 说明此前 >15 V 已损伤稳压电路，需换板。
    5. **应答帧洪流**：读到第一个合法帧后立即 `reset_input_buffer()`；双轴连发之间留 15 ms 间隔。
  - **已固化到 `configs/default.yaml`**：
    - `serial_port: /dev/ttyACM0`、`baudrate: 115200`、`serial_rts: true`
    - `yaw_id: 1`、`pitch_id: 2`
    - `yaw_sign: 1`（`-20°` 逆时针向左）、`pitch_sign: 1`（`+15°` 抬头）
    - `yaw_offset_deg: 33.0`、`pitch_offset_deg: -17.0`（机械零位校平）
  - **人工反馈**：
    - ✅ 2026-11-21：串口链路打通，Ping 10/10；两颗舵机 ID 由 0 改为 1 / 2；双轴独立控制验证通过；`--sweep` 5 轮无卡顿。
    - ✅ 2026-11-22：方向符号与零位偏置标定；全行程限位 `Yaw [-90°, +90°]`、`Pitch [-30°, +45°]` 精准到位（误差 ≤ 8 步 / 4096），无碰撞、无拉线。
    - ✅ 2026-11-23：独立复验结论一致（115200 命中、ID 1 / ID 2 应答、11.9 V、四条指令 `exit 0`）。

## 阶段二：AC3104 双麦与 OV9281 相机

- [x] **任务 4：AC3104 声卡驱动、双通道采集与开机自愈**
  - **关键事实**：
    1. 芯片实为 **AC3104**（I2C `0x18`），**不是 WM8960**；驱动 `tlv320aic3x` + 自制 `aic3104.dtbo`。
    2. 输入固定 `LINE1L / LINE1R`；`Line2L/R` 与 `Mic3L/R` 必须关闭（悬空输入是噪声放大器）。
    3. 健康判据：静音底噪 RMS 约 `0.0005~0.0006`（≈ −43 dBFS），低频相干性 > 0.5，`dmesg` 无新增 `tlv320aic3x ... ASoC error`。
  - **⚠ 2026-11-23 故障归因**：静音 RMS 飙到 `0.22`、SED 12 秒 31 次虚警。六步排除（舵机串扰 / PGA 增益 / 声学噪声 / 风扇 / 悬空路由）后落到**内核层**：codec 寄存器初始化写入失败（`dmesg` 累计 1021 条 ASoC 错误，集中在每次取流开始）。修复：热重绑 `1-0018` codec + 重灌路由；已做成开机自愈服务 `aic3104-heal.service`（脚本 `/usr/local/bin/aic3104-heal.sh`）。
  - **人工反馈**：
    - ✅ 2026-11-22：`LINE1L/LINE1R` 底噪 `0.0002`；45 秒 9/9 拍手检出；正前 `+20.9 μs`、左 `-137.1 μs`、右 `+136.5 μs`（极性左负右正，反推有效间距 `0.047~0.050 m`）。
    - ✅ 2026-11-23：修复后 L `0.00210` / R `0.00266`，相干性 `0.936`，15 秒 0 虚警；`aic3104-heal` 手动启动输出「采集正常，无需自愈」。
    - ✅ 2026-11-24：路由偏离后按同流程恢复，20 秒双通道录音确认两路同时有声。
  - **每次恢复工作前先复核**：`amixer -c respeaker2micac sget 'Line1L Capture Mux'`（或跑一次 `systemctl start aic3104-heal`），再开始录音。

- [x] **任务 5：OV9281 取流与 YuNet 人脸检测**
  - **人工反馈**：✅ 2026-11-22：`640×400` 裸取流 112.6 FPS；YuNet `320×200` 检出 40/40、20.7 FPS、置信度 0.875 → 锁定默认检测器。✅ 2026-11-24：V4L2 backend 取流成功，实际相机 10 秒 128 帧中 109 帧检出。
